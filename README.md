# Temas Emergentes de Aplicaciones Web

Repositorio correspondiente al curso **Temas Emergentes de Aplicaciones Web**.

El curso tiene como propósito desarrollar la capacidad de diseñar, construir y desplegar aplicaciones web en **TypeScript**, aplicando arquitecturas full stack modernas, patrones de diseño, herramientas y buenas prácticas de la industria.

A lo largo del curso se trabajará en la construcción de soluciones con énfasis en:

* Calidad del software
* Seguridad
* Rendimiento
* Mantenibilidad
* Buenas prácticas de desarrollo
* Desarrollo profesional y ético

## Contenido del repositorio

Este repositorio se utilizará para almacenar las prácticas, ejercicios y proyectos desarrollados durante el curso.

Cada actividad se encontrará organizada en su propia carpeta e incluirá, cuando corresponda:

* Código fuente
* Archivos de configuración
* Documentación
* Evidencias de ejecución
* Resultados de las prácticas

La estructura se irá actualizando conforme avance el curso.

```text
Temas-Emergentes-de-Aplicaciones-Web/
│
├── PRACTICA 1/
├── PRACTICA 2/
├── PRACTICA 3/
└── README.md
```

## Unidad I

### Diseño de aplicaciones web con TypeScript

**Objetivo de la unidad:**
Diseñar una aplicación web conforme a los lineamientos de las arquitecturas full stack modernas en TypeScript.

### Semana 1 — Encuadre del curso y transición a TypeScript

Durante la primera semana se abordan los siguientes temas:

* Encuadre, objetivos, metodología y forma de evaluación.
* Diferencias entre JavaScript y TypeScript.
* Detección de errores mediante el sistema de tipos.
* Eliminación de los tipos durante la compilación.
* Configuración de un proyecto TypeScript.
* Uso del modo estricto.
* Diferencia entre transpilar y verificar tipos.
* Tipos seguros.
* Definición de estructuras de objetos.
* Uniones de literales.
* Migración de código JavaScript a TypeScript.

También se realizan ejercicios prácticos enfocados en comprender el funcionamiento de TypeScript y su integración dentro del flujo de desarrollo.
